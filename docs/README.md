# Xenia documentation map

This repository contains the public Xenia v0.1.1-paper.1 code release.

- `README.md` — start here: scope, quick start, examples, license, and citation guidance.
- `PROJECT_OVERVIEW.md` — concise project overview.
- `docs/HARNESS.md` — local Python environment, build/sync workflow, and test harness.
- `docs/KERNEL_AND_CHEMISTRY.md` — source IR, chemistry/source terms, Jacobians, and kernel contracts.
- `docs/ROADMAP.md` — historical roadmap and design context for the HD-to-MHD split.
- `RELEASE.md` — release provenance, tag convention, license boundaries, and paper linkage.
- `examples/` — runnable examples and archived example reports.
- `tests/` — the release test suite.
- `src/xmf/` — Python semantic layer and C/Kokkos kernel sources.
