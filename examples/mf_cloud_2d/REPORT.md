# 两流体激波打重云（KMC94 的两流体版）

Klein, McKee & Colella (1994) 云破碎题抬进两流体：激波**只存在于流体 A**
（轻，风），重云是**另一支流体 B**；两支之间唯一的耦合是 `sources[]` 里
的碰撞带。$K=0$ 时激波穿过 B 而云纹丝不动——分速度的存在证明，单流体
码画不出来；$K$ 大时风拖曳云，形变/剥离。无磁场、无辐射；类比口径
太阳风 / ISM，不写成 C 激波或日球结论。

```text
python examples/mf_cloud_2d/run.py --tier off|weak|mid|strong [--nx 256 --ny 128]
python examples/mf_cloud_2d/plot.py --tiers off mid strong
```

求解器 `hllc + plm + rk2`，CFL 0.4。WENO3 在云被摧毁
（$t\approx1.2\,t_{\mathrm{cc}}$，剥离丝低于分辨）时 `wind_vx` 出非有限值，
无 positivity 守护，换 PLM 后四档 × 两分辨率全活。这是如实记录的配方选择，
不是收敛性声称。

## 1. 设置（码单位）

盒 $[0,4]\times[-1,1]$，四边 `copy`。入射激波 $M_s=10$ 走初值：
$x<0.5$ 为 Rankine–Hugoniot 后态 $(\rho_{A1},P_{A1},v_{A1})=
(3.8835,\,124.75,\,9.5856)$，前场 $(1,\,1,\,0)$，$\gamma=5/3$。
激波后流超声速（$v_{A1}>c_{A1}=7.317$），左储层永远不受扰，`copy`
即正确的入流。

流体 B：云盘圆心 $(1.5,0)$、$r_c=0.25$、$\chi=10$、压平衡 $P_B\equiv P_0$；
云外是 B 自己的 $\rho=10^{-2}$ 均匀背景。**各流体自带压平衡**（流体间不
共享压强），云边缘是稳定接触间断——与经典单流体云题同一构造。

拖曳带（等质量，逐格严格动量反对称，无除法）：

$$\mathrm{d}\mathbf v_A = -K\,n_B(\mathbf v_A-\mathbf v_B),\qquad
  \mathrm{d}\mathbf v_B = +K\,n_A(\mathbf v_A-\mathbf v_B)$$

档位在拖曳时标上标定：$\tau_c=1/(K\rho_{A1})$，
$\tau_c/t_{\mathrm{cc}}=\infty/10/1/0.1$，$t_{\mathrm{cc}}=
\sqrt{\chi}\,r_c/v_{A1}=0.08247$。换档 = 换 `sources[]` 一条常数带（或空表），
核不动。

## 2. 主断言：$K=0$ 云纹丝不动

$K=0$（`sources: []`）跑到 $3\,t_{\mathrm{cc}}$，两分辨率下
`v_cloud_max = 0.0` **逐位**：流体 A 的激波/接触均匀穿过云区，B 上没有
任何力。右面板 $|\Delta\mathbf u|$：波前之后齐刷刷 $=v_{A1}$，波前处归零。

## 3. 拖曳四档：弱互穿、强锁定

$256\times128$，$t=3\,t_{\mathrm{cc}}$，云内（$\rho_B>1$）统计：

| tier | $K$ | $|\Delta\mathbf u|$ 云内均 | $|\Delta\mathbf u|$ 云内极值 | $v_{B,\max}$ | nstep | wall (s) |
|---|---:|---:|---:|---:|---:|---:|
| off | 0 | 9.585 | 9.592 | 0.000 | 1186 | 19.0 |
| mid | 3.122 | 1.763 | 2.546 | 9.083 | 1401 | 152.2 |
| strong | 31.22 | 0.527 | 1.334 | 12.752 | 1767 | 191.7 |

（$128\times64$ 同序：off 9.585/0.000；weak 8.889/2.042；mid 6.484 全局、
云内同量级/8.932；strong 8.760 全局/12.428。）

mid 档云被拖到 $x\approx2.2$，杯形剥离形态与经典云破碎同族；strong 档
云内 $|\Delta\mathbf u|\approx0.5\ll v_{A1}$，锁定。$|\Delta\mathbf u|$ 的
全局极大在波前刚过处（B 尚未追上），不在云上。

![](output/paper_panel.png)

两点如实记录：

- strong 档风与云都出现 $v>v_{A1}$（极值 12.75）。动量交换严格反对称，
  总动量守恒；超额来自非平衡混合介质的压强梯度再加速——$P_{A1}=124.75$
  对 $P_B=1$ 的弛豫，是物理不是越界。
- 云外 B 背景也被拖曳（比力不含 $n_B$），所以 $|\Delta\mathbf u|$ 图上
  「锁区」是整个扫过区，云以滞后斑块显形——这正是功能演示要的图。

## 4. 守恒与边界

动量交换守恒不在本例测：单元级 `test_a2_conservation` 覆盖
（四流体总动量漂移 $\sim1.5\times10^{-11}$）。本例四边开放，闭盒动量
无意义（墙给冲量口径）。全程正密度正压、场有限由 `run.py` 断言。

网格收敛不是本例声称（功能性演示）；$128$ 与 $256$ 两分辨率形态一致、
云内统计同序，即报告的全部。
