# rad_hd_1d 结果报告（A5）

默认：`nx = 128`，`ng = 2`，`n_beam = 53`，`tstop = 2000 s`
（新指数初值下 \(\Delta t\) 很紧，不再默认 \(10^6\,\mathrm{s}\)）。
下面 §2–§4 数字仍是旧 \(r^{-2}\) 初值、\(t=10^6\,\mathrm{s}\) 那一跑。
HLL + PLM + RK2，`cfl = 0.4`，
球对称 \(r \in [R_p, 10 R_p]\)。
数字来自本次 `python examples/rad_hd_1d/run.py`。

行星重力单独作用很容易把没撑住的气往里拉，\(v_r<0\) 是正常的，
不是核写反了。缺的是恒星潮汐把 Hill 半径以外解绑。重力用旧树形式

\[
\mathrm{d}v_r = -GM_p/r^2 + 3GM_\star r/a^3
\]

（\(M_\star=1.119\,M_\odot\)，\(a=0.04707\,\mathrm{AU}\)）。Hill 约 \(4\,R_p\)：
底处净加速度仍向内（\(-850\,\mathrm{cm\,s^{-2}}\)），顶处向外
（\(+115\,\mathrm{cm\,s^{-2}}\)）。

## 1. 初值

`pack_ic` 在 `setup` 之后按格心半径填两支。原先 \(n\propto(R_p/r)^2\)
在 \(r\gtrsim 1.1 R_p\) 比 \(t=10^6\,\mathrm{s}\) 的风高两到七个量级，
球对称通量守恒要把多余质量慢慢扔出去。现改为薄指数包络
（\(H_{\mathrm{ic}}=0.04 R_p\)，地板 \(10^{6}\,\mathrm{cm^{-3}}\)），只在钉死的
\(r=R_p\) 处顶到 \(n_{\mathrm{beg}}\)：

\[
n_{\mathrm{HI}}(r)=\max\bigl(10^{13}\,e^{-(r-R_p)/H_{\mathrm{ic}}},\,10^{6}\bigr),\quad
n_{\mathrm{HII}}=10^{-3}\,n_{\mathrm{HI}},\quad
T=1500\,\mathrm{K},\quad
v_r=0,\quad
P=n k_{\mathrm{B}}T.
\]

`x1beg=user` 用解析带子只给 **ghost** 赋底层 \((n,v=0,P)\)，
不再钉最内活动格（旧地板缓冲在薄指数初值旁会造出
\(10^{13}/\)近真空的每步跳变）。`x1end=outflow` 仍拷最外层。

下面 §2–§4 的数字和图仍是旧 \(r^{-2}\) 初值那一跑；换包络后要重跑才对。

| 量 | 底（最内格，不钉） | 顶（\(9.965 R_p\)） |
|---|---|---|
| \(n_{\mathrm{HI}}\) (cm⁻³) | \(\sim 4\times10^{12}\)（指数） | \(10^{6}\)（地板） |
| \(n_{\mathrm{HII}}\) (cm⁻³) | \(\sim 4\times10^{9}\) | \(10^{3}\) |
| \(v_r\) (cm/s) | 0 | 0 |
| \(T\) (K) | 1500 | 1500 |
| \(a_{\mathrm{net}}\) (cm s⁻²) | −850 | +115 |

## 2. 末态速度（t = 1.0e6 s）

内区仍被行星重力拉着（底层钉 \(v=0\)，紧邻格子 \(v_r\) 略负），
过 Hill 后翻成外流。到 \(10^6\,\mathrm{s}\) 时过零已经进到
\(\sim 3\,R_p\) 以内。顶层 \(v_r\)：on 的 HI / HII 为 29 / 33 km s⁻¹，
off 约 29 / 29 km s⁻¹。

| 量 | radiation on | radiation off |
|---|---|---|
| \(v_{r,\mathrm{HI}}\) 最小 / 最大 (cm/s) | −3.50e5 / **2.91e6** | −3.50e5 / **2.90e6** |
| \(v_{r,\mathrm{HII}}\) 最小 / 最大 (cm/s) | −2.31e5 / **3.29e6** | −1.66e5 / **2.85e6** |
| HI 底 / 顶 \(v_r\) (cm/s) | −6.75e4 / **2.91e6** | −8.53e4 / **2.90e6** |

## 4. 球壳质量流 \(\dot{M}_s = 4\pi m_s n_s r^2 v_r\)

稳态球对称风要求 \(\partial_r(4\pi r^2 \rho v_r)=0\)。HI↔HII 会互转，所以
单组分不必平，氢的总和 \(\dot{M}_{\mathrm{HI}}+\dot{M}_{\mathrm{HII}}\) 才该平。
底层附近是大幅负尖峰（重力内流），线性轴会把外面的风压成一条零线，
所以左图用 symlog，右图只画 \(r>4.5\,R_p\)。\(m_{\mathrm{HI}}=m_{\mathrm{HII}}=1.00794\,\mathrm{amu}\)。

| | on | off |
|---|---|---|
| \(\dot{M}_{\mathrm{tot}}\) 中层 / 顶 (g/s) | 9.35e9 / 9.29e9 | 2.27e9 / 2.69e9 |
| \(r>4.5 R_p\) 均值 (g/s) | **9.35e9** | 2.45e9 |
| 同一区域 std/\|mean\| | **8.0e-4** | 6.7e-2 |
| 顶层 \(\dot{M}_{\mathrm{HI}}/\dot{M}_{\mathrm{tot}}\) | 0.024 | 1.00 |

开辐射的外区总和已经平到 0.08%：质量在球壳之间是守的，风接近稳态。
关辐射还在爬坡（7%），外流更弱、更中性，还没坐稳。
\(9\times10^9\,\mathrm{g\,s^{-1}}\) 与 Xing, Yan & Guo (2023, *ApJ* 953:166)
同一量级——A5 这条链（潮汐 + 光化 + 球对称 \(\dot{M}\)）对得上旧科学结果。

## 5. 读法

1. **负速度不是 bug。** 只有行星重力时，\(v=0\) 初值撑不住，气往里掉。
   潮汐把 \(r\gtrsim 4 R_p\) 解绑之后才会外逃。
2. **\(2\times10^5\,\mathrm{s}\) 不够。** 加到 \(10^6\,\mathrm{s}\) 之后，
   开辐射的 \(\dot{M}_{\mathrm{tot}}(r)\) 才在外区拉平。声学穿越仍大约
   \(4\times10^6\,\mathrm{s}\)，底层钉边界、压强梯度也还不是静力。
3. **辐射管成分，不管「能不能逃」。** 顶层速度开关辐射同一量级；
   电离和 \(\dot{M}\) 的担子从 HI 换成 HII。
4. **复合温度地板。** 关辐射外层会碰到 \(P=10^{-30}\)，工厂复合式用
   \(T_{\mathrm{HII}}+1\,\mathrm{K}\)，初温 1500 K 上相对改动约 0.07%。
