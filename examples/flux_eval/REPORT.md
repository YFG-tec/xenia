# 1D HLL × 面插值（pcm / plm / weno3）

固定 `shock_tube()` Sod：HLL + RK1，\(\gamma=5/3\)，CFL = 0.4。只换 `numerics.reconstruction`。**\(t_\mathrm{stop}=0.60\)**（默认管 \(0.15\) 的 4 倍）。精确解是无限域 Toro（`utils/riemann`）；这么晚稀疏/激波已靠近反射壁，\(L_1\) 用来比三家相对好坏，不拿来对契约测上界。

```text
python examples/flux_eval/run.py
```

契约测 `tests/test_recon.py`：**21 passed**。本报告不替代 pytest。

## 1. 默认分辨率：谁更尖

\(n_x=256\)。PCM 仍是格心当界面；PLM 是 van Leer 斜率插到 \(i+1/2\)；WENO3 是 Jiang–Shu 三点。三家都活着，没有负密度/负压。

| recon | nstep | \(\overline{\Delta t}\) | \(L_1(n)\) | \(L_1(v)\) | \(L_1(P)\) | 相对 PCM（\(n,v,P\)） |
|---|---:|---:|---:|---:|---:|---|
| pcm | 85 | 7.13e-3 | 7.74e-3 | 1.41e-2 | 6.35e-3 | 1 |
| plm | 89 | 6.74e-3 | 2.04e-3 | 3.43e-3 | 1.41e-3 | 0.26 / 0.24 / 0.22 |
| weno3 | 89 | 6.78e-3 | 2.30e-3 | 4.18e-3 | 1.51e-3 | 0.30 / 0.30 / 0.24 |

PLM 把 \(L_1\) 压到 PCM 的约 1/4；WENO3 紧随其后（约 1/3）。步数略多，是因为锋面更尖，CFL 用的 \(\max(|v|+c)\) 稍大。PCM 的 \(L_1(n)\) 与 `rk_eval` 同设置的 RK1 逐位同量级（7.74e-3），说明本刀没动 Riemann / RK。

![](output/profiles_nx256.png)

右行激波附近（\(x\in[7.2,9.2]\)）差得最明显：PCM 抹了好几格，PLM / WENO3 贴着精确解的台阶。

![](output/profiles_nx256_shock.png)

这道 Sod 上 **PLM 略好于 WENO3**。WENO3 在光滑段是三阶，碰到间断会把权打到单侧模板，比 van Leer 多一截耗散。契约测 \(t=0.15\) 已经是这个排序（plm \(L_1(n)=1.92\times10^{-3}\)，weno3 \(2.39\times10^{-3}\)），拉长时间以后没翻盘。

## Appendix. HLL + RK3

同一管、同一 CFL = 0.4、同一套重建，只把 `numerics.rk` 换成 `rk3`。主文数字不动。

\(n_x=256\)：

| recon | rk1 \(L_1(n,v,P)\) | rk3 \(L_1(n,v,P)\) | rk3 / rk1（\(n\)） |
|---|---|---|---:|
| pcm | 7.74e-3 / 1.41e-2 / 6.35e-3 | 8.56e-3 / 1.75e-2 / 7.47e-3 | 1.10 |
| plm | 2.04e-3 / 3.43e-3 / 1.41e-3 | 2.38e-3 / 4.31e-3 / 1.58e-3 | 1.17 |
| weno3 | 2.30e-3 / 4.18e-3 / 1.51e-3 | 3.04e-3 / 5.68e-3 / 2.27e-3 | 1.33 |

换 RK3 **没有把 \(L_1\) 压下去**，三家都略差于 RK1。这和 `rk_eval` 在 PCM 上看到的一样：CFL = 0.4 时空间误差主导，前向 Euler 多出来的耗散对这道 Sod 的 \(L_1\) 反而稍有利。面插值把空间误差砍掉之后，RK3 相对 RK1 的差距还在（PLM 约 17%，WENO3 约 33%），没有翻盘。排序仍是 **PLM < WENO3 < PCM**。
